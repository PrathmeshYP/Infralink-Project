# Infralink Project

## Overview

Infralink Project is a web-based application designed to manage and streamline infrastructure-related processes.  
The project follows a modular architecture with separate frontend and backend components, making it scalable and easy to maintain.

---

## Project Structure

Infralink-Project/
- Backend/
- Frontend/
- README.md
- .gitignore
- package.json

---

## Features

Backend:
- RESTful APIs
- User authentication and authorization
- Database connectivity
- Business logic handling

Frontend:
- User-friendly interface
- Responsive design
- Form handling and dashboards
- Communication with backend APIs

---

## Installation and Setup

1. Clone the repository

git clone https://github.com/PrathmeshYP/Infralink-Project.git  
cd Infralink-Project

2. Backend Setup

cd Backend  
npm install  
npm start

3. Frontend Setup

cd Frontend  
npm install  
npm start

---

## Requirements

- Node.js (version 14 or above)
- npm
- Database (if applicable)

---

## Running the Project

Make sure both frontend and backend servers are running.

Frontend URL:  
http://localhost:3000

Backend API URL:  
http://localhost:5000

---

## Environment Variables

Create a .env file inside the Backend folder and add:

PORT=5000  
DB_HOST=your_database_host  
DB_USER=your_database_user  
DB_PASSWORD=your_database_password  
JWT_SECRET=your_secret_key

---

## API Usage

APIs can be accessed using:

http://localhost:5000/api
